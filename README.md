# 나의 할 일 (TodoList)

> 하루의 할 일을 빠르게 추가하고, 완료하고, 정리할 수 있는 차분하고 완성도 높은 개인용 TodoList 웹 애플리케이션입니다.

본 프로젝트는 불필요한 백엔드, 로그인, 외부 폰트/이미지 종속성 없이 순수 로컬 브라우저 환경에서 동작하는 웹앱입니다.

---

## 1. 주요 기능

### 1) 할 일 추가
- **입력 편의성**: Enter 키 또는 `추가` 버튼으로 빠르게 등록.
- **입력 유효성 검증**: 앞뒤 공백 자동 제거(trim), 빈 문자열 및 공백만 있는 입력 차단, 최대 200자 제한.
- **한글 IME 안전성**: 한글 자모 조합 중(`isComposing`) Enter 입력 시 의도치 않게 등록되거나 중복 제출되지 않도록 방어.
- **연속 입력 흐름**: 추가 완료 후 입력창 자동 초기화 및 포커스 유지.
- **최신순 정렬**: 새로 등록된 항목은 항상 목록 최상단에 배치.
- **조건부 가림 안내**: 현재 필터나 검색어로 인해 새 항목이 화면에서 가려질 경우 안내 문구와 `전체 보기` 원클릭 복귀 버튼 제공.

### 2) 완료 상태 관리
- **체크박스 토글**: 체크박스 또는 할 일 텍스트 클릭 시 완료/미완료 즉각 전환.
- **시각적 구분**: 완료된 항목에 명확한 취소선 및 부드러운 텍스트 색상 적용.

### 3) 인라인 내용 수정
- **수정 모드**: 항목의 `수정` 버튼 클릭 시 인라인 입력 필드로 즉각 전환되며 자동 포커스.
- **저장/취소**: Enter 키 또는 `저장` 버튼으로 반영, Esc 키 또는 `취소` 버튼으로 취소.
- **유효성 검사**: 빈 내용으로 수정 방지 및 한글 IME 방어.
- **포커스 복귀**: 수정 완료/취소 후 원래의 `수정` 버튼으로 포커스 자동 복귀.

### 4) 개별 삭제 및 실행 취소 (Undo)
- **삭제 피드백**: 항목 삭제 시 하단에 플로팅 토스트(“할 일을 삭제했어요.”)와 `실행 취소`, `닫기` 제공.
- **데이터 완전 복원**: 실행 취소 시 원래의 id, 내용, 완료 상태, 생성/수정 일시 및 원래 정렬 위치로 완벽 복원.
- **혼동 방지 설계**: 빠른 연속 삭제 시에도 최신 1건이 안전하게 실행 취소 대상으로 유지됨.

### 5) 필터 및 검색
- **상태 필터**: `전체`, `진행 중`, `완료` 필터 지원 (`aria-pressed` 준수로 스크린 리더 지원).
- **실시간 검색**: 대소문자 구분 없는 실시간 부분 문자열 검색 및 원클릭 검색어 초기화(`✕`) 버튼.
- **교집합 필터링**: 상태 필터와 검색어가 동시에 안전하게 조합되어 동작.
- **명확한 빈 상태**: 전체 목록 없음, 검색 결과 없음, 조건별 없음 상태를 구분하여 친절한 안내와 액션 버튼 제공.

### 6) 완료 항목 일괄 삭제
- **안전한 모달 대화상자**: 완료된 항목이 있을 때만 버튼 활성화.
- **삭제 대상 명시**: “완료한 할 일 N개가 삭제됩니다. 이 작업은 되돌릴 수 없습니다.” 확인 다이얼로그 제공.
- **키보드 접근성**: 모달 열림 시 기본 취소 버튼 포커스, 내부 포커스 트랩(Tab 순환), Esc 닫기 및 배경 클릭 시 취소.

### 7) 현황 및 진행률 표시
- **실시간 통계**: 전체 수, 완료 수, 남은 할 일 수 실시간 집계.
- **진행률 막대**: WAI-ARIA `progressbar` 속성을 준수하며, 할 일이 0개일 때 0으로 나누기 오류(NaN%) 방지(0% 기본 표기).

## 2. 저장 방식 및 제한사항

- **저장 위치**: 현재 사용 중인 기기의 **브라우저 로컬 저장소(`localStorage`)**에만 저장됩니다.
- **데이터 스키마**: `todo-app:v1` 네임스페이스와 `schemaVersion: 1` 기반으로 구조화되어 유효성 검사 후 안전하게 저장됩니다.
- **클라우드/동기화 부재**: 별도의 계정 로그인이나 서버 백엔드, 클라우드 동기화가 제공되지 않습니다. 브라우저 캐시/사이트 데이터를 삭제하거나 시크릿 창을 닫을 경우 데이터가 초기화될 수 있습니다.
- **오류 복원력**:
  - 스토리지 파싱 실패나 손상된 데이터 발견 시 원본 데이터를 덮어쓰지 않고 보호하며, 사용자에게 경고 배너를 안내합니다.
  - 브라우저 용량 초과(`QuotaExceededError`) 등으로 저장에 실패하더라도 앱은 크래시 없이 메모리 상에서 계속 동작하며, 푸터에 실패 안내 문구와 `저장 다시 시도` 버튼을 표시합니다.

## 3. 실행 및 빌드 명령

### 요구사항
- Node.js 18 이상 (Node.js 20, 22, 26 호환)
- npm 9 이상

### 개발 서버 실행
```bash
npm run dev
```

### 테스트 실행 (Vitest + Testing Library)
```bash
npm run test
```

### 프로덕션 빌드
```bash
npm run build
```

### 프로덕션 미리보기 (Preview)
```bash
npm run preview
```
