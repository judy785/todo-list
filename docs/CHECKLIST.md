# TodoList 구현 및 QA 체크리스트

## 1. 기능 요구사항
- [ ] 할 일 추가: 엔터키 및 추가 버튼 동작
- [ ] 앞뒤 공백 제거(trim) 및 빈 문자열 차단
- [ ] 최대 200자 제한
- [ ] 한글 IME 조합 중 엔터 중복 등록 방지
- [ ] 추가 후 입력창 초기화 및 포커스 유지
- [ ] 최신 항목 상단 표시 (createdAt 내림차순)
- [ ] 완료 상태 토글 (체크박스 및 시각적 취소선/뮤트)
- [ ] 인라인 수정 (수정 버튼, Enter 저장, Esc 취소, 빈 내용 방지)
- [ ] 개별 삭제 및 실행 취소(Undo) 토스트 알림
- [ ] 필터 (전체, 진행 중, 완료)
- [ ] 검색 (내용 검색, 필터와 교집합, 초기화 버튼)
- [ ] 완료 항목 일괄 삭제 (확인 대화상자, 대상 개수 표시, 취소 가능)
- [ ] 현황 표시 (전체, 완료, 남은 수, 진행률 % 및 0개일 때 0% 방어)
- [ ] localStorage 자동 저장 및 스키마 검증 (v1)

## 2. 반응형 및 디자인
- [ ] 360px 모바일 레이아웃 (가로 스크롤 없음)
- [ ] 768px 태블릿 레이아웃
- [ ] 1440px 데스크톱 레이아웃
- [ ] 긴 한국어 문장 및 연속 공백 없는 문자열 줄바꿈 (`overflow-wrap: anywhere`)
- [ ] DESIGN.md 색상 및 디자인 토큰 준수

## 3. 접근성
- [ ] 키보드 내비게이션 (Tab, Shift+Tab, Enter, Space, Esc)
- [ ] 명도 대비 4.5:1 이상
- [ ] 스크린 리더용 ARIA 레이블 및 라이브 리전 (`role="status"`, `aria-pressed` 등)
- [ ] 모달 포커스 트랩 및 복귀
